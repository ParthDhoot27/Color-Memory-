Game Rules

1. Winning Condition

Only completing the full sequence makes you win the round. If you fail in between, you get partial points for each color you remembered correctly.

2. Scoring System

• Round 1: 100 points

• Round 2: 150 points

• Round 3: 200 points

• Round 4 and above: 100 points for each color

• 50 points for each correct color in any round sequence

• If you lose in between, you get only 50 points per correct color

• If you win the round, you get 100 points per color

3. Replay Chances

After 2 consecutive wins, you get 3 chances to see the sequence again. These can be used anytime after the sequence is shown.
